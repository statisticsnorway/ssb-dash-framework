# Implementation plan: HB methodology module for SSB Dash Framework

- The current implementation plan outlines the tasks and responsibilities for developing the HB methodology module within the SSB Dash Framework. It serves as a guide for both the AI-assisted development and user approval process. It uses `architecture_design_detailed` and the destilled `architecture.md` as the main source of implementation guidance, also `altinnapiclient-documentation.md`. Keep them up to date with decisions made underway. 
Ensure that any deviations from the architecture are documented and approved through this plan. See also `ssb-vaskify-design` for relevant design considerations.
- Issues are located in `Issues.md`.

- This plan is based on Implementation order list outlined in `Implementation order list.md`. It follows the structured sequence of tasks required to develop the HB methodology module, ensuring that each step is clearly defined, testable, and approved before proceeding to the next. The implementation history is managed by the developer. Each row is it's own clearly defined task with its associated details and status.
- Expect the developer to batch add tasks in to current tasks, and ask questions or seek clarifications whenever uncertainties arise.
- When developer pastes a step into the chat, you are supposed to act on that step. 
- Re-read the document often, as this document will be changed often.
- Preserve existing AI-solution suggestions as history; put new or revised proposals in the AI follow-up column.
- Treat each AI-response cell as one communication: keep one proposal or question in each cell, and split separate concerns into separate task rows.
- Do not fill in User fields; they are reserved for user input and approval only.
- ONLY WORK ON THE AFFECTED TASK
- When tasks use all the discussion space, mark it as research and add a new row for continued discussion.
- When cell has the letter `a` it means approved by the user.
- Separate tasks clearly by responsibility and ensure each has its own row in the implementation plan.
