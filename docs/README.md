## The structure of the documentation

The source of truth for architecture and design decisions can be found in [docs/architecture.md](architecture.md).

For supported datamodels see [docs/datamodels.md](datamodels.md)

For examples of how to build and configure apps, look in the [demo folder](../demo/).

For tips, tricks and unsupported/unintended ways to manipulate the functionality of an app, you can consult the [docs/arcane_compendium.md](arcane_compendium.md).

The *norsk* folder contains documentation for SSB internally. It is intended to be used for beginners and will be limited in the amount of topics covered. The focus is on on-boarding.

You can find the reference documentation in the docstrings, and as a part of the github pages.

For information about how to contribute to the project, please see the [Contributor Guide].

Note that the "sphinx" folder is for auto-generating documentation and not relevant for non-developers.
